# nvm + node
```
sudo apt update && sudo apt install -y curl build-essential && curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.8/install.sh | bash && export NVM_DIR="$HOME/.nvm" && . "$NVM_DIR/nvm.sh" && nvm install --lts && nvm alias default 'lts/*' && node -v && npm -v
```
